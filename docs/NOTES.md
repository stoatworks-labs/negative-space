# Negative Space — working notes

Repo-local notes. Cross-cutting fleet knowledge lives in
[fleet-notes](https://github.com/stoatworks-labs/fleet-notes).

## Status — 2026-08-27

v0.1.0, first build. Engine, all six export paths and the UI are complete and tested
(81 tests). Not yet deployed, not yet on GitHub, not yet in the backend's `projects.json`.

## Decisions already made

**Millimetres, not metres.** LED pitch is quoted in mm by every manufacturer. An SI-metre
engine would put the tool's most important number at 1e-3.

**A separate repo from `blend-calc`.** Edge blending is about surfaces that overlap; this is
about surfaces that do not touch. They share a file layout and a Resolume exporter shape,
and nothing else. Merging them would put two unrelated geometries in one engine.

**Gutters are merged bands, not adjacent pairs.** Holds for ragged layouts where "the gap
between A and B" is undefined but "the columns nothing lights" still is.

**The JSON export is the project, not the design.** Saving solved outputs would be saving a
cache: reopened after a rounding change it would contradict what that version computes, with
no way to tell which was right.

## Traps that have actually bitten

**Gutter extents were canvas-relative while `respaceGutter` compared them against absolute
surface positions.** Caught by re-reading before it shipped. Gutter `startMm`/`endMm` now
include the canvas origin.

**A full-width gutter band painted over a crossing gutter's label.** Invisible to every test
that only parsed the SVG — found by rasterising with `rsvg-convert` and looking at it. Fixed
by drawing all bands, then all labels, with labels a quarter along rather than centred.

**Two equal 100 mm gaps came out 38 px and 39 px** and the first test assertion assumed they
would match. The behaviour is right (absolute rounding prevents drift along a row); the
assertion was wrong. Now pinned by a test named in capitals so nobody "fixes" it.

## Known gaps

- **No PWA.** Needs `sw.js`, `manifest.webmanifest` and generated icons — see the fleet PWA
  pattern note. Skipped rather than half-shipped.
- **No About dialog or support footer.** Vendored from `stoatworks-backend/about` and
  `support-footer`, generated from its `projects.json`. Add this repo there, run the sync
  scripts, then restore the version-stamping plugin in `vite.config.ts` (blend-calc's copy
  is the model).
- **No `ATTRIBUTIONS.md`.** The fleet's `sync-attributions.py` should be run once the repo
  is registered.
- **The Resolume file has never been opened in Arena.** The single most valuable next check.
- **No Dockerfile / docker-compose.** Those are generated by
  `stoatworks-unraid/scripts/gen-docker.mjs` from `fleet.json`; add the repo there rather
  than hand-writing them.
